川上ウマウマレース v23

【大会モード追加】
・主催者が1〜10レースから開催数を選択
・各レースごとに競馬場とG1レース名を設定
・参加は主催者が表示するQRコードのみ
・参加前に「参加しますか？ はい／いいえ」を表示
・参加者の馬と騎手は大会中そのまま維持
・馬番は毎レース自動シャッフル
・単勝／複勝の購入ポイントを各レースで集計
・全員10,000ptスタート
・購入ポイントを差し引き、的中払戻を加算
・各レース終了後に途中ランキングを表示
・最終レース後に総合順位と優勝者を発表
・全レースの勝ち馬履歴を表示

【既存機能】
・端末1台でみんなで遊ぶ秘密入力モード
・有名馬、有名騎手、オリジナル馬・騎手
・脚質別の大げさなレース展開
・ゴール前は僅差へ滑らかに収束
・映像順位、実況、確定結果、払戻を同じ順位データで統一
・オンライン限定ムチ操作
・文字実況
・レース別オリジナルG1風ファンファーレ

【更新方法】
ZIPをiPhoneの「ファイル」アプリでタップして解凍し、
中の6ファイルをGitHubの既存ファイルへまとめて上書きしてください。
