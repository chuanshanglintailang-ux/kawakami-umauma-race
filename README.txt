川上ウマウマレース v21

【主な改善】
- 逃げ・先行・差し・追込のレース運びを大幅強化
- 大逃げ、途中失速、中団進出、直線一気など目まぐるしい展開
- 最終10%で公式ゴール時刻へ滑らかに収束し、映像と結果を統一
- オンラインではレース名横に自分の馬番・馬名を大きく表示
- 先頭表示を大型化し、馬番色で識別
- 音声実況を廃止し、文字実況のみに変更
- ゲートイン、オリジナルG1風ファンファーレ、カウントダウン、ゲート開放を追加
- レース名ごとに異なるオリジナルファンファーレパターン
- ムチの連打回数表示を廃止。各プレイヤーの馬へ個別に効果
- 「次のレースへ」で参加メンバー・馬・騎手・能力・脚質を保持
- 端末1台モードは、同じメンバーのまま次戦へ進むか、1人ずつ秘密編集を選択可能
- オンラインはルームを維持したまま、自分の名前と馬名を編集して次の馬券画面へ進める

※ファンファーレはゲーム用のオリジナル音源であり、JRA等の実際の音源・楽曲は使用していません。
※オンライン機能はPeerJSを利用します。主催者はロビー画面を開いたままにしてください。


【v21変更点】
・オンライン参加方法をQRコードのみに変更
・終盤80%以降に全馬が急接近し、ゴールは僅差になるよう映像と公式ゴール時刻を再設計
・レース別ファンファーレ音源の差し替え機構を追加

【ファンファーレ音源について】
著作権者から正規に利用許可を得た音源だけを使用してください。
audioフォルダに指定名のMP3を置くと優先再生し、存在しない場合はゲーム内オリジナル音源へ自動的に切り替わります。
