川上ウマウマレース v49

【v49の重要修正】
- オンライン大会は毎回10,000ptから開始します。
- 大会の総合結果を表示した時点で、各端末の所持ポイントを10,000ptへ自動リセットします。
- 総合結果画面には大会終了時の最終順位とポイントをそのまま表示します。
- 主催者・参加者とも、単勝または複勝を選んで「この買い目で確定」を押します。
- 主催者が自分の馬券を確定しても、レースは自動では始まりません。
- 全員の馬券が確定するまでは、主催者のレース開始ボタンを無効化します。
- 全員準備完了後だけ、主催者が「全員準備完了・レース開始」を押せます。
- 開始直前にも全員の確定状態を再検証し、未確定者がいる場合は開始を拒否します。
- 参加者の切断・プロフィール変更・次レース移行時は準備状態を更新します。
- 不正な馬番、券種、金額、所持ポイント超過の準備データは受理しません。

【維持している内容】
- v48の大会内ポイント増減と払戻計算
- v47のiPhone向け軽量描画
- ファンファーレとゲートの「パンッ！」音
- ムチ機能なし
- 単勝・複勝の確定馬券スナップショット
- QRコードによるオンラインルーム参加

VercelへZIPの中身をそのままデプロイしてください。
