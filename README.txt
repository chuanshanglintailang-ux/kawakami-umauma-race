川上ウマウマレース v16

【主な機能】
・単勝／複勝、能力から勝率とオッズを自動計算
・映像のゴール順と確定結果を同じ公式順位データで統一
・全馬が停止せず、最後まで抜きつ抜かれつする約30秒レース
・ルーム名を入力して作成、合言葉またはQRコードで参加
・オンライン馬は全能力90＋追加10ポイントを自由配分
・全画面に戻るボタン、iPhoneの画面見切れ対策
・リプレイ機能

【オンラインの注意】
PeerJSを利用した主催者接続方式です。主催者がページを閉じるとルームは終了します。
会社・学校・一部Wi-Fiでは通信制限により接続できない場合があります。

【更新方法】
ZIPを解凍し、中の6ファイルをGitHubリポジトリ直下の同名ファイルへ上書きしてください。
VercelはGitHubの更新後、自動で再デプロイされます。


【v16追加】
・歴代／現役／海外の有名騎手を収録
・馬を選んだ後に騎手を選択（ひとりモード）
・騎手ごとの能力補正を勝率／オッズへ反映
・オンライン用のオリジナル騎手名と騎手タイプ
・残り約400mからムチ連打ボタン
・ムチ操作を実際の走りと確定順位へ反映
※騎手の能力補正値はゲーム用の架空設定です。

【v16追加】端末1台パーティーモード
- 2〜12頭を自由選択
- 馬番ごとに端末を渡して、馬名・騎手名・脚質を秘密入力
- 決定後は入力欄を即消去し、前の人の内容を次の人に表示しない
- 全員登録後に一斉公開し、5秒後に自動でレース開始
- パーティーモードは全馬同能力で公平
- 入力したオリジナル馬名・騎手名を文字実況と対応端末の音声実況で読み上げ
- ムチ操作はオンライン（主催・参加）のみ。パーティーとひとりモードでは非表示
